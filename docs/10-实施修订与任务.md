# 实施修订与任务

2026-09-26。用户授权保留风格、补齐关键设计并开始开发。本文覆盖 docs/01—08 中冲突的旧描述，其余原约束继续生效。

## 决策

1. 首批交付项目、角色管理及 A 关卡。创建项目同时创建 waiting_gate/character 的准备运行，无需预先确认角色；运行不入 ARQ，占位 Worker 不接收任务。后续开始/恢复端点由 LangGraph 推进。
2. A 确认提供 run_id、anchor_version、reviewer。服务端锁项目/角色，校验运行归属、阶段、版本，写不可修改的 ReviewGate 快照；同一运行内同版本重复确认幂等。修改角色递增版本、取消 confirmed，保留旧审核。确认不推进尚未实现的 B。
3. B 绑定 run/storyboard_version，C 绑定 run、shot/version、image_attempt_id。视频另存 accepted_video_attempt_id 并终审。后续迁移随模块增字段；初始迁移声明目前实际模型。
4. 付费调用前实现数据库预算预留、结算/释放、未知结果对账；项目/类型/镜头额度同事务变更，预留+消费不得超过上限。现有 charge 不代表已完成防超支。
5. 持久化 run、能力、请求哈希、供应商任务 ID 和状态；重放返回已有结果，未知结果禁止降级重发；每次实际请求单独计量。Provider 按能力+供应商索引。
6. 并发租约包含所有者、续租、条件释放，不以固定 60 秒计数锁覆盖长视频任务。
7. QC 五维分数必填且为 0–1 有限数值；非法不得回退 0。低置信度转人工，blocked 不自动重试；保持 0.4 / 0.6 阈值，在接模型前完成。
8. 缺陷为评估正类：TP=正确拦坏，TN=正确放好，FP=误杀，FN=漏放。召回率 TP/(TP+FN)，误杀率 FP/(FP+TN)；待审单列，零分母返回 null，校准/评估样本分离。
9. SSE 支持广播/重放与最后事件位置；替换竞争式 BLPOP，验证双客户端和重连。
10. 本机单用户阶段绑定 loopback；公网部署前验收鉴权/权限/限流/秘密管理。示例数据不作实测指标。

## 批次与验收

- M1：项目/角色、锚定预览、版本化 A 确认、预算读取、初始迁移、React 页面。真实 MySQL 测重复名称、并发/旧版本、跨项目审批、修改失效、审核留痕；Ruff/mypy/pytest，前端 lint/typecheck/build，浏览器操作验证。
- M2：预算预留、Provider 记录、幂等、限流租约；假 Provider 测失败/超时/并发后再接真实图像；未通过前禁止付费调用。
- M3：严格 QC、参考图、图像重试、黄金集和对照；真实联调前配置密钥并核实价格/额度。
- M4：LangGraph、B/C、恢复、SSE；随后少量视频、FFmpeg、导出终审和部署。
