# 页面与交互规格

2026-09-26：用户确认保留 design/ 中的深色工作台风格。本文件替换原先损坏的截断摘要，作为实现依据。

## 视觉与技术

- React + TypeScript + Vite，原生 CSS；沿用 backend/，新增 frontend/。
- 背景 #0f0f1a，面板 #1a1a2e，选中 #252540，主要操作 #4ecdc4，辅助强调 #8b7cf6。
- 主文字 #eeeef5，次级文字 #b0b0c4；正文 14px 起，标题 20–28px。状态同时显示文字。
- 左侧导航、顶部标题与主操作、内容卡片；项目无素材时用渐变占位，有素材后显示接受帧。
- 桌面多列，窄屏自动减少列数，表格横向滚动。键盘焦点可见，字段有 label，弹窗支持 Escape 和焦点返回。
- 原图中的金额、成功率和素材都是示例，不导入业务数据库。无数据时显示空状态或“尚无样本”。

## 第一批可操作范围

1. 项目：分页、搜索、创建、详情；预算以元输入、整数分提交。摘要可录入现有剧本，不调用模型。
2. 角色与锚定：选项目、建角色、编辑五组结构化特征、预览稳定 Prompt、主观词告警、人工确认。
3. 创建项目时建立准备运行，停在 A 关卡。确认必须带 run_id 与 anchor_version，并写快照；修改后旧确认失效。
4. 预算页读取所选项目真实账本；没有调用时费用为零，不展示虚构趋势和 ROI。
5. 分镜、质检页面显示后续能力说明；未实现操作不伪装成成功。

## 后续关键交互

| 页面/操作 | 输入与反馈 | 放行约束 |
| --- | --- | --- |
| 分镜工作台 | 左侧场景/镜头，中间候选图，右侧构图、动作、角色版本，底部进度 | 明确项目/run；按叙事顺序展示，生成可按场景分组 |
| A 角色确认 | 特征、版本、参考图审核状态、确认人 | 旧版本 409 要求刷新；新增/修改需重新确认 |
| B 分镜审核 | 镜头列表、时长、角色、修订版本；确认或驳回说明 | 当前角色版本通过 A；绑定 run 与分镜版本 |
| C 图像合规审核 | 候选图、QC 五维结果、参考帧；选择具体 attempt | 未通过 QC 或 blocked 不可放行；图像通过才能生成视频 |
| 视频/导出 | 被选视频、总时长与缺失镜头 | 视频终审后才能导出；不能把 locked_attempt_id 图像当视频 |
| 暂停恢复 | 预算不足/重试上限/待人工/远端结果未知；显示已保留成果 | 只续跑未完成工作；未知付费结果先查询 |
| 成本页 | 项目、run、日期筛选；已花费、预留、剩余 | 金额统一元；预计避免支出与实际账单分开；指标附公式/样本量 |

请求提供加载、空数据、失败重试和提交中状态。失败保留输入，成功刷新真实数据。客户端禁用重复提交，服务端仍须校验并发/版本。当前本机单用户工具不向公网发布；公网部署前另行验收鉴权与权限。
